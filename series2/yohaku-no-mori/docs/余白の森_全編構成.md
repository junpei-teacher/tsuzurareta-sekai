## 0. この文書の境界

本書は、仮素材で単一エンディングまで開通するための接続、イベント、戦闘、素材数を固定する。
世界法則は `シリーズ設定書.md`、画面とシステム契約は `余白の森_設計書.md`を優先する。

次は意図的に決めない。

- 国、村、森、遺跡の固有名
- セナ以外の人物の固有名
- 指輪の製作者と年代
- セナが抹消対象になった直接の罪状
- HALVENが終幕へ関与する具体的な方法

役職名やパネルIDは制作上の識別子であり、固有名を決めたことにはしない。

## 7. 全素材台帳

### 7.1 背景

- 固定画面用レイヤーセット：25
- 遠景の基礎系統：村、境界、浅森、深森、遺跡外、遺跡内、最奥の7系統
- 中景：25。画面固有の会話対象と接続を担う

- 記憶用の色抜け差分：共同倉、最奥の2系統

遠景は再利用できる。中景と前景は接続や調査対象が違うため、完成素材の台帳上は別に数える。

### 7.2 人物

- 仮面、左手、指輪は必要に応じて別レイヤー

## 8. 最終戦の状態遷移

```text
最終休息
  └─ checkpoint作成
       └─ GUARDIAN
            ├─ 通常呪文 → 通常解決
            ├─ SENA入力 → 「まだ届かない」／消費なし／GUARDIAN継続
            ├─ 敗北 → checkpointから再戦
            └─ 致死ダメージ → HP1で停止
                              └─ CALL（決定的な忘却）
                                   ├─ 不一致 → 情景反応／CALL継続
                                   ├─ 記憶をたどる → 段階救済 → CALLへ戻る
                                   ├─ 再戦 → checkpointへ戻る
                                   └─ SENA完全一致
                                        └─ 会話 → 和解 → 単一ED
```

CALLではResolver、MP、敵行動、時間制限を使わない。`SENA`は攻撃でも呪文登録でもない。
