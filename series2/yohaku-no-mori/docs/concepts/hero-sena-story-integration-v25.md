# 主人公・セナの本編演出合成 v25

> 日付：2026-09-08  
> 状態：DEV実景合格（後続v26で本番採用）  
> 対象：終戦演出、単一エンディング3頁

## 1. 目的

v24で接地をそろえた茶髪主人公とセナを、人物比較板だけでなく物語上の実景へ一時接続し、次を同時に確認する。

- 最終戦後に、仮面・左手・指輪の動きがセナ本人の身体として読める。
- 共同倉、夕暮れの村道、王国へ続く道で、背景・文字・UIと人物が競合しない。
- 生成PNGを採用しても、仮面、指輪、演出光、進行状態をコード層へ残せる。
- DEV比較が本番の保存や配布資産を変えない。

## 2. 実装境界

- `src/fx/storyCharacterLayer.ts` に、物語Sceneが人物の出所を知らずに描ける任意レイヤー契約を置いた。
- `src/fx/generatedStoryCharacters.ts` はv24の待機・歩行PNGをDEVでだけ読み、主人公とセナを同じ32×48規格で描く。
- セナの左手は生成身体の該当領域をeven-odd clipで抜き、同じ姿勢のコード手を描き直す。原本PNGは変更しない。
- 仮面は顔だけ、指輪は左手外縁だけのコード層とする。指輪の反応光は、向きとコマから得た実際の指輪座標を使う。
- `SenaRevealScene` と `Series2EndingScene` の第3引数は任意である。通常進行では渡さずコード人物を維持し、DEV入口だけ `GeneratedStoryCharacterLayer` を渡す。
- DEVのエンディングはクリア保存を書き換えず、終了時は開発メニューへ戻る。

## 3. 終戦演出の確認

DEVの「終戦　仮面を外す」では、次の操作を使える。

- `P`：PNG候補／コード基準
- `T`：停止／再生
- `←` `→`：0.25秒ずつ時刻移動
- `R`：先頭から再生

1.03秒の仮面姿、1.28秒の仮面離脱・左手下降・指輪反応、1.78秒の離脱後を比較した。左手は二重に残らず、3px下がった手と袖の間もコードの橋渡しで切れない。指輪反応は左手の実座標へ追従した。

画面記録：`sena-reveal-png-v25.jpg`、33,556 bytes、SHA-256 `c906f42da38605243c74adcf259be93a1f55f1659300dd8620cd2f2c55f3724c`。

## 4. 単一エンディングの確認

DEVの「単一エンディング」はPNG候補を初期表示し、`P`でコード基準と比較できる。2026-09-08にさらに `T`、`←` `→`、`R` を追加し、村道の停止時刻を固定して検査した。

- 共同倉：人物、配給袋、樹脂瓶、本文が重ならない。
- 夕暮れの村道：0.18秒後に歩き始め、2.9秒で指定位置へ到着する。
- 3.40秒：入力解禁時は移動完了済みで、二人とも歩行4コマ目の両足が揃う姿勢にいる。
- 3.52秒：待機1コマ目へ自然に戻る。
- 王国への道：人物は手前の暗い地面、問いは左上、王国と校訂光は右奥に分かれ、シリーズ3への視線が一本道でつながる。
- 実ブラウザの警告・エラーは0件。

村道の時刻計算は `src/scenes/endingMotion.ts` へ純粋関数として分離した。`npm run verify:character-story-integration` が開始位置、2.9秒の移動完了、3.40秒の中立足、待機復帰、通常／DEV経路の境界を検査する。
