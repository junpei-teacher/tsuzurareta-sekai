| | |

三作目が読む場所は1つでなければならない。二作目の設計書は

### シリーズの形（決定）

- 舞台は**王立書庫の外側**。ある町の話、別の部族の話、というように**一作＝一つの土地**
- **時代は自由。** 未来でも過去でもよい。並べる軸は年表ではなく、
  「その時代・その土地で**何が名前を書き留めていたか**」である
- **主人公は毎作別人。** 一作目の見習いは戻らない（4.4）
- **各作に「魔法との出会い」を一度だけ描く**（1章 シリーズの型）
- **戦闘と詠唱は保存する。** 全作で同じものを使う（5・6・7章）
- メタ（一作目 2.6「この世界を書いた者」＝`QOTHREN` の先）は**保留**。
  シリーズの最後まで取っておく札で、二作目では開けない

### 題名の体系（決定）

「焚書の夜」は**サブタイトルへ下げる。** シリーズ名を上に立てる。

> # 綴られた世界
> ### ―焚書の夜―

推す理由は3つ。

- **「綴る」がこのシリーズの遊びそのものである。** 綴り（スペル）と、本を綴じること。
  一作目の呪文『綴じる傷』で既に使っている語なので、語彙が揃っている
- **受け身の題**なので、禁書の前提を先に言ってしまわない。
  「誰が書いたのか」に触れずに「書かれている」だけを出せる
- **土地も時代も縛らない。** 町の話でも部族の話でも未来の話でも題が浮かない

没にした対案（記録として残す）：

| 題 | 何を名指しているか | 弱点 |
|---|---|---|
| **綴られた世界**（採用） | 世界の状態 | 「綴」が少し硬い |
| 世界の原文 | 禁書という物 | 学術語に聞こえる。ただし謎は強い |
| 名を書く者たち | 各作の主人公 | 「書く者」でない主人公の作を作れなくなる |

**副題に番号は付けない。** 一作目が「夜」なので「第一夜／第二夜」で揃えると、
昼の話・何日もかかる話が作れなくなる。`綴られた世界　―焚書の夜―` の形だけを守る。

## 1. シリーズの背骨

一行しかない。

> **名前は、誰かが書き留めないと消える。**

この一行には**二段ある**（法則12 を決めたので、混ぜないこと）。

| | 誰が持っているか | 消えるとどうなるか |
|---|---|---|
| **存在** | **禁書だけ。** 世界に一冊 | 初めからいなかったことになる |
| **痕跡** | 目録・当番表・貸出票・墓石・人の記憶 | 誰かがいたことを、確かめる手が無くなる |

**書庫の紙は痕跡でしかない。存在を支えてはいない。**
だが一作目の最後にプレイヤーが持っているのは、まさにその痕跡だけである——
`MIRA` という綴りを覚えているのは、世界でもう主人公ひとりだけで、
**痕跡が消える前に禁書へ持っていけるかどうか**、という話になっている。

二作目は、この二段のどちらから入ってもよい。
**痕跡の側から入るほうが書きやすい**（人が一人消え、その人の書いた紙も一緒に消えている）。

この背骨から自動的に決まることが3つある。**決め直す必要はない。**

- 敵は「忘れられたもの」であり、火や鉄では終わらない。**名前だけが届く**
- プレイヤーの武器は記憶である。装備でも数値でもない
- したがって**主人公が強くなる手段は、言葉を知ること以外に無い**

### シリーズの引き継ぎは、セーブデータではなく人間の頭で起きる

このシリーズは、**プレイヤーが覚えた綴りがそのまま次作の初期装備になる。**
一作目を遊んだ人は、二作目の最初の戦闘で `ROZHA` と打てる。データは何も渡っていない。
**続編を作る意味が、この一点で他のRPGと違う。** ここを設計の中心に置くこと。

### シリーズの型（毎作これを守れば繋がる）

| | 決め |
|---|---|
| 主人公 | **毎作別人。** 前作の主人公は戻らない（4.4） |
| 最初の一語 | **各作に一人、最初の言葉をくれる人物を置く。** 一作目のミラの役 |
| 魔法との出会い | 各作で**一度だけ**描く。**プレイヤーはもう打てるが、主人公は初めて打つ** |
| 舞台 | 一作＝一つの土地。町、部族、船、鉱山、修道院、なんでもよい |
| 時代 | 自由。**年表を作らない**（作ると縛りになる） |
| その土地の記録装置 | 何が名前を書き留めているかを毎作決める。**それが失われるのが話の芯**（1章） |
| 変えないもの | 詠唱・呪文帳・欠けた綴り・MP＝インク・レベル無し（5〜7章） |

**「プレイヤーはもう打てるが、主人公は初めて打つ」**——ここがシリーズ2作目以降の
いちばん美味しいところである。主人公が最初の一語を教わる場面で、
遊ぶ人の指はすでに `ROZHA` を覚えている。**教わる前に打ってもよい**設計にしておくこと。

**「最初の一語をくれる人」は、毎作いなくなる必要はない。** 一作目でミラを失ったのは
あの話の形だったからで、型として繰り返すと安くなる。

## 2. 世界法則（正典・変更禁止）

一作目が本文で成立させてしまったもの。**二作目はこれを説明し直してはならないし、覆してもならない。**

| # | 法則 | 一作目での現れ方 |
|---|---|---|
| 1 | **魔法とは言葉である。** 正しい語を口にすれば現象が起きる | 詠唱＝文字入力そのもの |
| 2 | 語の正しさは**人の解釈に依らない**。世界の側が決めている | ハッシュ関数（5.1）。誰が打っても同じ語は同じ現象 |
| 3 | **真の名は一つではない。** 言葉は違えど、同じ扉を叩く | 同じ効果に着地する綴りが複数ある（逆引きの副産物） |
| 4 | ゆえに国家は言葉を独占管理する。平民の詠唱は重罪 | 王立書庫＝管理の中枢。見習いは読むことを許されない |
| 5 | **禁書は、この世界の原文である。** 書けば存在したことになり、消せばいなかったことになる | 終章の白紙 |
| 6 | 書き換えには**代償がある。しかし誰も気づかない** | 目録から一枚だけ頁が欠ける |
| 7 | 名を消された者は**存在の跡だけが残る**。覚えている人間の中に、穴として | 司書長が四十年思い出せない見習い |
| 8 | 名を失くしたものは、**こちらの記憶を消しにくる** | 「忘却」＝呪文帳が読めなくなる |
| 9 | **言葉は配給されている。** 実用魔法は貴族と官の独占で、庶民には扱わせない | 巻物＝安くて狭い言葉。平民の詠唱は重罪 |
| 10 | **最大の刑は、名を消すことである。** 記録からではなく、存在から消える | 司書長の頭に空いた穴（四十年前の見習い） |
| 11 | **名を消された者には、言葉の管理が届かない。** 名簿の外にいるから | 魔物の使役——配給表に無い魔法が使われている |
| 12 | **写しは原文の影である。** 原文から名が消えれば、写しの文字も同時に消える。**逆は起きない** | 「貸出票の署名だけが、白い」／目録から欠けた一枚 |

### 書庫は宝物庫ではない。金庫である

**なぜ本がそれほど大事なのか、管理している当人たちは知らない。**
写字生も、おそらく下の司書も、説明されない側にいる。理由は2つあって、どちらも伏せられている。

- 呪文書は**力の配給表**である。庶民が読めるようになると、貴族と官の地位が揺らぐ
- 禁書は**世界の原文**である。ここに触れる者が世界を決める

だから書庫は本を「守っている」のではなく「**閉じ込めている**」。
一作目の主人公が本を運び、題名だけを書き写して**読ませてもらえない**のは、
この構造がいちばん下の人間に届いたときの形である。**格差はこの世界の前提であって、脇役ではない。**

### 刑罰が、そのまま抜け穴になっている（シリーズの動力）

名を消すのは最大の刑である。ところが名簿と記録で成り立つ管理は、
**名の無い者を管理できない。** 罰を受けた瞬間、その人間は
禁じられた言葉を自由に使える側へ落ちる。

> 最大の刑が、最大の自由になる。

国家はこの穴を塞げない。塞ぐには名を戻すしかなく、名を戻せば刑が消える。
**シリーズの敵も味方も、この穴から出てくる。**

### 影は一方通行である（**決定**）

**禁書と、ただの本を混同しないこと。** 力の流れは片側にしか流れない。

> **禁書（原文）→ すべての写し。** この向きだけ。

- 禁書から名が消えると、**その名を書いた紙の文字も同時に消える。**
  目録の署名欄が白くなり、貸出票の署名が抜け、当番表からその行が失われる。
  誰かが漂白したのではない。**勝手に消える**
- **逆は絶対に起きない。** 目録を焼いても、署名を削っても、原文は動かない

#### 「写しを消せば原文が消える」を採らなかった理由

一度そう書いた。だが**それを許すと、あらゆる本が禁書と同じ働きを持ってしまう。**
紙の名前を消して回れば世界を書き換えられることになり、
**禁書が一冊しかないことの意味が丸ごと消える。** この案は破棄した。

#### したがって、こうなる

- **名を消す刑は、禁書でしか執行できない。** 触れるのは国のごく限られた者だけである。
  司書長も写字見習いも、その現場を見たことがない
  （「見た者はいない。見た、と言う者もいない」と両立する）
- **書庫を焼いても、名前は消えない。** 焼けるのは言葉と記録であって、存在ではない。
  `HALVEN` が火をつけたのは抹消のためではなく、**下へ降りるため**である（3.0-5）
- 神話呪文『焚書』`DIZO` は、刑罰の魔法ではない。**ただの大火力である**
- 一作目の「貸出票の署名だけが、白い」は、**四十年前に原文から名が消えた瞬間の跡**である。
  誰も手を触れていない。だから司書長には、穴の記憶だけが残った

**説明しない、という規約も引き継ぐ。** 1〜12は本文で語らない。
プレイヤーは「打つ」という行為を通してこれを理解する。
**冒頭に世界設定の語りを置くことを禁止する**（オープニングで置けるのは、その作品の3つの前提だけ）。

## 3. 一作目が確定させたもの（シナリオ軸と引き継ぎ台帳）

### 3.0 一作目のシナリオ軸（確定版）

通しの筋は7段。**本文になっているのは 1・2・3・7 で、4・5・6 は
紙の上の痕跡としてしか出ていない。** だからそこが続編の資産になる。

1. **本は世界の記録装置である。** だが管理している当人——司書・写字生——は理由を知らない。
   運び、埃を払い、題名を目録に書き写す。**読むことは許されない**
2. **呪文書は力の配給表である。** 実用魔法は貴族と官が独占し、庶民には扱わせない。
   書庫は宝物庫ではなく金庫であり、格差の維持装置である（2章）
3. **禁書は世界の原文である。** 罪人は名を消される。記録からではなく、存在から。
   **それが最大の刑**であり、司書長の頭に空いた穴（四十年前の見習い）がその痕跡である
4. **ところが名を消された者は、言葉の管理の外へ出る**（法則11）。
   だから彼らは禁じられた魔法を使える。**魔物の使役もその一つ**
5. **`HALVEN` は、名を消された者である。** 四十年どこにも書かれていない名だから、
   命令書の筆跡が「見慣れない」。彼は焼却命令を通し、魔物を連れた焚書隊を書庫へ送った。
   目的は禁書に自分の名を書き戻すこと。**そして途中で、格差そのものを書き換えられると気づいた**
6. **彼は書庫に着いていない。** 火が上がり、兵が入り、命令書が床に落ちる。
   **主人公のほうが先に降りる**
7. **最下層にいたのは、四十年前に降りて、そのまま言葉を失った見習いである。**
   名が無いので顔も無く、火も氷も雷も通らない。届くのは名前だけ。
   これは **`HALVEN` の成れの果て**であり、同時に**ミラがこれからなるもの**でもある。
   そして主人公は、`MIRA` を覚えている世界で唯一の人間として白紙の前に立つ

#### この軸にすると、置きっぱなしだった物が全部繋がる

| 一作目に置いてあった物 | 何だったのか |
|---|---|
| 焼却命令書。**理由の欄は空白** | 理由を書けない命令だった。彼の理由は紙に書けない |
| **署名の筆跡が見慣れない** | 四十年、どこにも書かれていない名前だから |
| 「この一語のために、書庫が燃えている」（ch2） | そのままの意味である |
| 焚書隊が魔物を連れている | 名を持たない者が使える魔法。国家の配給表には無い |
| 兵士「建物を焼けとある。中の者をどうしろとは書いていない」 | 命令を出した者は、人を焼くことに関心が無い |
| 司書長が四十年思い出せない名 | 消された者は、覚えている人間の中に穴として残る |
| 返しそびれた本を四十年抱えた見習い | 降りた者は、外へ出られない |
| 「三十七番の棚だけ埃がない」 | 毎晩読んでいるのは司書長。**彼も理由を探していた** |

#### ここは私の推測が入っている（**壊してよい**）

- **`HALVEN` と最下層の見習いを別人にしてある。** 一作目の本文で最下層の相手は
  「四十年前にこの階段を降りた見習い」であり、言葉を失って動けない。
  一方 `HALVEN` は外で紙を動かしている。**同じ人物にはできない。**
  そこで「四十年前に名を消されたのは一人ではない」とした。
  **降りて言葉を失った者**と、**外へ出て自分の名を書き続けた者**がいる
- **彼の動機を二段にしてある。** 名を取り戻すために降りようとし、
  途中で**原文そのものを書き換えられる**と気づいた、という順。
  本編では明かさないので、二作目で好きに決められる
- **一作目の本文に手を入れる必要は無い。** この軸は全部、既に置いてある物の解釈である

### 3.5 書庫の紙と、そこに残る名前（一作目の実データ）

**ここを取り違えていたので、正確に書いておく。**
書庫の紙が記録しているのは**本**である。人ではない。

| 紙 | 何が書いてある | 人の名は |
|---|---|---|
| 目録 | 題名・書架番号・署名 | **書いた本人の署名**（「目録には、書いた者の署名が要る」） |
| 貸出票 | 持ち出した本 | **持ち出した本人の署名** |
| 巡回当番表 | その夜の当番 | **当番の署名**（いちばん上が `MIRA`） |

つまり**書庫で名前が紙に残るのは、他人を管理した結果ではなく、
自分が手続きとして署名した結果である。**

- 司書長にも写字見習いにも、**人の存在をどうこうする権限は無い。**
  彼らがやっているのは蔵書の管理だけである
- それでも紙は溜まる。四十年ぶんの目録には、四十年ぶんの署名が積んである
- **その署名は、原文の影にすぎない**（法則12）。原文から名が消えた瞬間、
  ここの文字も勝手に消える。**書庫の紙は、存在を支えていない**

だから司書長が持っているのは記録ではなく、**穴**である。
四十年ぶんの目録をめくっても、その見習いの署名だけがどこにも無い。
書いた覚えはあるのに、頁には無い。**ch3 の「貸出票の署名だけが、白い」がその現物である。**

**この世界で人を存在させられるのは禁書だけで、書庫の紙にできるのは
「誰かがいた」という痕跡を持つことだけである。** そして名が消えれば、その痕跡も消える。

### 3.6 写字見習いとは何か（身分と仕事）

**「読んではいけないのに写字をする」の中身。**

- **写すのは、本の外側の文字だけ。** 背表紙の題名、目録の記入、貸出票、当番表。
  **中身は写さない**（「題名を書き写す。中身は読まない。それが決まりだ」）
- **中身を写すのは、身分のある写字生と官の仕事**である。呪文書の複製は力の配給に直結するので、
  下の者には触らせない。見習いはその工房のいちばん外側にいる
- したがって見習いは**読み書きができる。だが読むことを禁じられている。**
  字が書けなければ目録を書けないので、**中途半端に教育された低い身分**という位置になる
- **「読むな、しかし署名しろ」。** これがこの世界の身分そのものである。
  力のある文には触れさせないが、責任は取らせる

**庶民は、この建物に入らない。** 借りに来るのは官と貴族である。
つまり**庶民の名は書庫のどこにも残らない。** 格差は「魔法が使えない」だけではなく、
**紙に名前が残らない**という形でも効いている。
庶民は、誰かがいたという痕跡すら持てない。

ミラが禁を破って本の**中身**を読んだのは、だからこの世界では越境である。
主人公が最初に覚える `ROZHA` は、**身分の壁を越えて渡ってきた一語**ということになる。

## 4. 一作目の結末をどう継ぐか

一作目は結末が24本＋断章40本ある。**続編は正史を1つ決めないと書けない。**
決めないまま書くと、どの結末を選んだ人にも嘘をつくことになる。

### 4.1 推し案：**空欄エンディング「本を閉じる」を正史にする**

書き換える力を手にして、書き換えなかった。**あれを起点にする。**

理由は3つ。

1. **他の23本を否定しない。** 世界を書き換えていない結末だから、
   「あなたが見たあの結末も起こった」を潰さずに済む。書き換えた結末を正史にすると、
   別の結末を選んだ人の一周が続編によって無かったことにされる
2. **背骨と噛み合う。** 名は書き留められなかった。だから消えていく。
   **外の世界で名前が消え始めている状態が、二作目の初期条件になる**（1章）
3. **一作目でいちばん重い結末**であり、続編はその重さの続きから始められる

したがって二作目の時点で確定しているのはこれだけである。

> 王立書庫は焼けた。蔵書は失われた。
> 誰かが最下層まで降りたのかどうかは、**誰も知らない。**
> 焼却命令書の署名は、消されていない。

**一作目に触れるときは、この温度で書くこと。** 誰が降りたかを二作目が名指ししない。

### 4.2 断章40本・結末24本の扱い

**捨てない。「起こりうった世界」として温存する。**
二作目で「そうならなかった世界の噂」として一行だけ出す、という使い方はできる。
ただし**ミラを生きた人物として再登場させてはならない。**
あれは禁書に `MIRA` と書いた人だけが手に入れた結末で、続編が全員に配るものではない。

### 4.3 セーブの引き継ぎ

一作目のキーは `funsho-no-yoru/v1`（`src/game/save.ts`）。
二作目は**自分のキーを持つ**。読むだけならしてよいが、**呪文帳の中身を戦力として引き継がない。**

理由：二作目の主人公は一作目の主人公ではない。**その人物が綴りを知っている理由が無い。**
そして引き継ぐ必要も無い。**プレイヤーの頭の中で既に引き継がれている**からである（1章）。

やってよい引き継ぎは1つだけ。**「集めたもの」に前作の記録として並べる。**
呪文帳・断章・結末を、二作目の収集画面から**読めるだけ**にする。力は渡さない。

### 4.4 一作目の主人公の呼び方（重要な制約）

**名前がプレイヤー入力なので、二作目は一作目の主人公を名前で呼べない。**
呼べるのは役と関係だけである。

> 「見習いが一人、降りていったという話は聞いた」
> 「名は、誰も書き留めなかった」

**これは制約ではなく、背骨そのものである。** 一作目の主人公は、
名前を書き留められなかった者として二作目に存在する。**筋が通っている。**
司書長が一作目で名前を呼ばれない（3.1）のと同じ理由で、二作目でも
中心人物の一部は役名で通してよい。

## 5. 引き継ぐシステム — 凍結レベル

### 5.1 レベルA：絶対凍結（シリーズの物理法則）

**変更した瞬間に、シリーズ全作の呪文名が別物になる。**

| 対象 | 場所 |
|---|---|
| `normalizeWord`（trim → 大文字 → A-Z0-9 以外を捨てる） | `src/spell/hash.ts` |
| `spellHash`（FNV-1a 32bit、basis `0x811c9dc5`、prime `0x01000193`） | 同上 |
| 帯の境界（`1000 / 4700 / 8200 / 9700 / 10000`） | `src/spell/resolver.ts` |
| **帯のサイズ（`20 / 20 / 12 / 5` ＝ 計57）** | 同上（5.2） |
| `r = h % 10000` と `q = floor(h / 10000)` の役割分担 | 同上 |
| `MIN_WORD_LENGTH = 3` | 同上（下げると一字で上級に当たる穴が開く） |
| `endingKey` の正規化（重複を除き、**語順を問わず**、`\|` で連結） | `src/ending/resolve.ts` |
| 3.3 の18語＋`MIRA`＋`QOTHREN` | `data/spells.json` |

`src/spell/hash.ts` の先頭にある凍結コメントは、**二作目にもそのまま持っていくこと。**

### 5.2 帯のサイズも凍結される（見落としやすい）

帯内の個体は `q % 帯のサイズ` で決まる。
つまり**サイズを1つ変えると、その帯の全語の着地先がずれる。**
「二作目で呪文を10個足す」は `size: 20 → 30` を意味し、
`ROZHA` が残り火でなくなる。**呪文を増やす形での拡張はできない。**

### 5.3 二作目の新呪文は「空いている39枠」から取る

57枠のうち、**綴り（`canonical`）が決まっているのは18枠だけ。**
残り39枠は `origin: "discovery"` で、日本語名と数値はあるが**綴りが決まっていない。**

> **二作目の新呪文は、この39枠に `tools/spell-forge.ts` で綴りを与える。**
> 帯もサイズも触らない。世界に新しい語が「見つかった」ことになる。設定とも一致する。

39枠あれば三作目まで足りる。**枠が尽きるまで、帯には手を出さないこと。**

どうしても新しい呪文空間が必要になったとき（例：他国の言語体系）は、
**帯を増やすのではなく、別のハッシュ空間を持つ第二の表**として実装する。
一作目の語は一作目の表で解決され続ける。この場合も 5.1 は無傷である。

### 5.4 レベルB：作品ごとに決め直してよい

| | 一作目の値 |
|---|---|
| 各呪文の威力・MP・属性・演出 | 巻物初級 MP2／中級 7〜11／上級 14〜20／神話 40〜60 |
| HP・MP の章ごとの値 | 30/90 → 70/140 → 150/200 |
| 属性相性（誰が何に弱いか） | 書庫の生き物と召喚物は**無属性に耐性**、地下の言葉だけが浴びる |
| 回復道具の入手数 | インク壺 2/3/3、魔力の雫 0/1/2 |
| 敵・戦闘数 | 10種、15〜25戦 |
| 章の数と構成 | 3章＋終章 |

**ただし 5.4 を動かすときは `npm run balance` の下限を守ること。**
「章を抜けたあと、何回ぶん乱打できるMPが残るか（下限30回）」が
このシリーズの遊びを守っている数字である（9章）。

### 5.5 レベルC：引き継がない

マップ、部屋、章構成、敵の顔ぶれ、曲、立ち絵。**全部作り直してよい。**
二作目は屋外がある可能性が高いので、1部屋＝1画面（28×14）の縛りは
そこで見直してよい（ただし 8章の理由を読んでから）。

## 9. 設計原則（一作目で払った授業料）

**この章がいちばん価値がある。** 全部、実際に作って壊してから書いたものである。

1. **測れる数字を目標にしてはならない。**
   `MIRA` の露出を25回まで積んで、「MIRA 言い過ぎ」「他人のようで感情移入できない」と言われた。
   回数を最大化した結果、彼女が署名を書く装置になった。書き直し後、自分の名を綴るのは2回だけ。
   **位置がすべてを決める。** 数字は床であって、目標ではない。
2. **尺を設計値にしてはならない。** 「約60分」から逆算していたころ、
   真っ先に削られたのは第1章の日常——**いちばん削ってはいけない場所**だった。
3. **節約が最適解になった瞬間、発見の遊びは死ぬ。**
   MPを厳しくしたら「知っている単語しか使わない」になった。MPを3倍にして、
   希少なものを**手番**へ移した。緊張は消さず、置き場所を変える。
4. **隠すと遊びが生まれる。** 相性表を常に出していたら試し打ちをしなくなった。
   一覧が見えるのは『見抜く』を唱えているあいだだけにした。
5. **積み上がったものは、必ずその場で言う。** 掘り当てたときだけ黙っていたら
   「保存が効いていないのでは」と疑われた。書き出しもその場で行う（閉じたぶんが消える）。
6. **到達経路の無い中身を作らない。** 結末24本のうち8本が到達不能だった
   （名前入力が無い／その呪文の入手経路が無い）。**結末を足す前に、そこへ至る道を確かめる。**
7. **後から出てくる人物は負ける。** `HALVEN` を新キャラとして出したら
   「突然出てきて、つながりが不明。必要ないのでは」と言われた。役を司書長に寄せ、
   `HALVEN` は署名だけにした。**第1章からいる人物と、四十年ぶんの具体物には勝てない。**
8. **章の頭に、状況の地の文を置く。** 第1章だけ無くて、
   何をする夜かも、話す相手がいることも分からないまま放り出していた。
9. **ルールは説明せず、存在だけを感じさせる。** 「原文は有限」を機構にすると
   最後の一手が算数になる。代償は本文で描き、誰も気づかない形にした。
10. **往復させる部屋には、読むものを置く。** 置かないと「話しかけるだけの作業ゲーム」になる。
11. **言いっぱなしの糸を作らない。** ミラが「三十七番の棚」と言うのに、
    その棚が世界に存在していなかった。
12. **検証は目でやらない。機械で見る。**
    `npm run balance`（詰みとMP残量）／`lint:script`（枠からはみ出す台詞）／
    `reach`（塞いで通れなくなった床）／`verify:dist`（帯の出現率）／
    `forge`（綴りの逆引き）／`frames`（歩行のコマごとの背丈）。
    **二作目でも、同じ種類の検証を最初に作ること。** 後から作ると、もう手遅れの場所が見つかる。
13. **明るくしたら、UIも明るくする。** 絵の減色をやめた瞬間、
    それまで読めていた文字が読めなくなった。目の順応が上がるからである。

## 10. 二作目の空白

### 10.1 一作目の本文から、もう決まっていること（外の世界について）

**これは設定というより論理的な帰結である。** 二作目はここから出発する。

- **蔵書一切の焼却を命じられる権限が、書庫の外にある。** そして
  **理由の欄は空白のまま通る。** 理由を書かずに命令が実行される機構が存在する
- **`HALVEN` の筆跡は「見慣れない」。** 四十年目録を書いた男が知らない筆跡である。
  **書庫の人間ではない**
- **兵は命令で動いていた。魔物は命令書に無い**（法則11）。
  つまり隊の中に**国家の配給表の外側の力**が混ざっていた。連れてきたのは `HALVEN` の側である
- **配給された言葉は安くて狭い**（巻物＝初級 MP2）。**大魔法は失われている**（発掘）。
  外の世界では、人々は安い言葉だけで暮らしている
- **平民の詠唱は重罪。** 取り締まる者・裁く場・記録が外にある
- **格差は書庫の外にある。** 呪文書を読める者と読めない者の線が、そのまま身分の線である
- **名を消された者たちは外にいる。** 一人ではない（3.0）。管理の外にいるので、
  **国家より自由に言葉を使える。二作目の敵も味方もここから出る**
- **管理の中枢が焼けた。** 失われたのは**言葉と記録**であって、存在ではない（法則12）。
  外の世界は「配給元が消えた」状態で二作目に入る。
  **呪文の巻物はもう補充されない。誰がいたかを確かめる紙も、もう無い**
- **禁書は無傷である。** 地下は焼けていない。**書き込める場所は、まだそこにある**
- **禁書の存在を知る者は外にいない。** 「見た者はいない。見た、と言う者もいない」

### 10.2 まだ何も決まっていないもの（自由に決めてよい）

国の名／地理／年代／言語／書庫以外の建物／貨幣／王／
焚書のあと世界がどうなったか／司書長の名／**四十年前の罪状**／
**禁書に触れられるのは誰か**（刑の執行者。ごく限られた者、とだけ決めてある）／
**その土地で名前を書き留めている装置**（作品ごとに決める。1章 シリーズの型）／
この世界を書いた者。

**決めたら、この文書の3章に書き足すこと。**

### 10.2.5 シリーズの終着点（構想）

**最後の敵は、書庫を管理してきた王国そのものである。**

- 禁書を独占することで身分のしがらみを作り、自分たちを裕福にしてきたのは王族と貴族である
- 彼らは世界を書き換えたいのではない。**いまの世界のままでいたい。**
  だから原文に触らせない。管理とは、変えないための仕組みである
- `HALVEN` はその外側から来た者で、**敵ではあっても最後の敵ではない**

**シリーズを閉じるときは、この線に着地する。** ただし急がない。
二作目でいきなり王を出すと、一作目で `HALVEN` を先に出して失敗したのと同じことになる（9-7）。
**先に、格差が人の暮らしに出ている形を1作ぶん見せること。**

### 10.3 やってはいけない継ぎ方

- **禁書を二つにしない。** 原文は一冊。増やすと「書けば現実になる」の重みが割れる
- **原文を書庫の外へ持ち出さない。** あの部屋は持ち出させないために彫られた
- **ミラを生きた人物として出さない**（4.2）
- **一作目の主人公を名前で呼ばない**（4.4）
- **`HALVEN` を、紙の上での存在感を積む前に登場させない。**
  一作目の失敗（9-7）がそのまま繰り返される。
  **署名・命令書・回状・名簿——先に紙で会わせてから、最後に人を出す**
- **経験値・レベルを足さない。** 強くなる手段は言葉だけである（1章）
- **「打つ」以外の主行動を足さない。** 増やした分だけ詠唱の主役性が減る
- **名を消された者を、ただの被害者にもただの悪にもしない。** 穴から出てくる者は両側にいる（2章）
- **国家を単純な悪にしない。** 穴を塞げないから管理を続けている。
  そして管理側の下働き（司書長・写字生）は、**四十年、人を存在させ続けていた側**である
- **その作の主人公に、「本がなぜ大事なのか」を最初から知らせない。**
  一作目と同じ順序を守る。**当たり前のことを、人は口に出さない**

## 11. シリーズ共通のやらないことリスト

長さの話ではない。**手を広げると完成しないから作らない。**

- 経験値・レベル上げ
- ランダムエンカウント
- 装備システム
- パーティメンバー（**孤独が仕様**）
- ATB・リアルタイム要素・タイピング速度の評価
- 日本語IMEを使う入力
- 音声・ボイス
- モバイル対応（キーボード必須のため原理的に不可）

**最後の1つだけは、二作目で意識して選び直す価値がある。**
入口の狭さをシリーズで固定するのかどうかは、決めた覚えがないまま引き継がれている。

## 12. 二作目を起こす日の手順

1. **題名を確定する**（0章）。シリーズ名が決まらないと二作目の副題も決まらない
2. 二作目の土地で、**名前が消えたことに誰がどう気づくか**を一行で書く。
   消せるのは禁書だけなので（法則12）、**外の世界に出るのは必ず「兆候」である**
3. 4.1 の正史（本を閉じる）を採るかどうかを決め、この文書に記録する
4. **主人公と「最初の一語をくれる人」を先に決める**（1章 シリーズの型）。
   舞台より先である。**魔法との出会いの場面を1つ書けたら、その作は立つ**
5. リポジトリを複製し、`src/spell/hash.ts` と `resolver.ts` の**凍結コメントを保つ**
6. `save.ts` のキー名を変える。一作目のキーは**読むだけ**（4.3）
7. `data/` を空にする。ただし `spells.json` の18語（3.3）は残す
8. 新呪文が要るなら `npm run forge` で**39枠の中から**綴りを取る（5.3）
9. 検証ツールを最初に用意する（9-12）。`balance` と `lint:script` と `reach` は初日に動かす
10. 章の頭の地の文を、部屋を作る前に書く（9-8）

## 13. 規模の広げ方（街とフィールドを持つ作を作るとき）

一作目は書庫の中だけ、8画面で完結した。二作目以降で街や外を出すときの決め。

### 13.1 「オクトパスを1/5にする」のではない。「オクトパスを1本ずつ出す」

あの手の作品が高いのは**8人ぶんの物語を1本に詰めている**からで、
1人ぶんの物語そのものは高くない。

**このシリーズは既にその形をしている**（毎作、主人公が変わる。1章 シリーズの型）。
1本に詰めずに、1本ずつ出す。**1作あたりの重さは、一作目の2〜3倍で止める。**
群像になるのは、シリーズが終わったときである。

### 13.2 カメラを入れない（最重要）

一作目が完成した理由の半分は **1部屋＝1画面（28×14）**で、
スクロールも、読み込みも、当たり判定の最適化も要らなかったことである。

**屋外もこの形のまま作る。** 画面の端まで歩いたら次の画面に切り替わる
（既存の `!door` と同じ仕組み）。追加コードは実質ゼロで、`.room` も `npm run reach` もそのまま効く。

**HD-2D の見た目は最初から狙わない。あれは技術ではなく物量である。**

### 13.3 街は「入れる建物」で死ぬ

家を全部歩けるようにすると、部屋数が一気に3倍になる。**入口で止める。**

| | 上限 |
|---|---|
| 街の画面数 | **6〜8**（通り・広場・門・裏路地・井戸端…） |
| **中に入れる建物** | **3つまで。** 残りは扉を調べると会話が出るだけ |
| 立ち絵を持つ人物 | **1作6人まで**（一作目と同じ。PixelLab の費用が人数に比例する） |
| 名前のあるNPC | 8人まで。ほかは「町の人」で、**3行×1回**しか喋らない |

**全員に長い会話を書くと、ミラで学んだのと同じ失敗になる**（9-1）。
量を増やすほど、一人ひとりが薄くなる。

### 13.4 世界地図は歩かせない

町と町のあいだを歩かせると、**そこに置くものが無限に要る。**
一枚絵の地図に点を打ち、行き先を選ばせる。道中は一行だけ書く。

> 　三日歩いた。途中で会ったのは、荷を引く男が二人だけだった。

### 13.5 量の上限を、作り始める前に決めて機械で守る

一作目の教訓（検証は目でやらない。9-12）を、**中身の量**にも使う。
`data/scope.json` に上限を書き、`npm run scope` が超えたら落ちるようにする。

```
画面 25 / 会話ファイル 4 / 名前つきNPC 8 / 立ち絵 6 / 敵 12 / ボス 3 / 新呪文 5
```

**上限は作り始める前に書く。** 後から書いたものは上限ではなく、現状報告である。

### 13.6 縦に1本通してから、横に増やす

**街1つ・外2画面・ダンジョン1つ・ボス1体**を、遊べる状態まで通す。
そこで面白くなければ、街を増やしても面白くならない。

バイブコーディングでは特に、**AIが一度に把握できる範囲**を超えた瞬間に失速する。
`.room` のアスキーマップと JSON の会話を保つこと（設計書 7.1／7.4）。
**Tiled のような GUI エディタを入れてはいけない。** AIが読めない資産ができる。

### 13.7 二作目の現実的な目安

| | 一作目 | 二作目 |
|---|---|---|
| 画面数 | 8 | **25** |
| 立ち絵 | 6 | 6 |
| 敵 | 10 | 12 |
| 新呪文 | 18 | **5**（39枠から。5.3） |
| 戦闘・詠唱・呪文帳・セーブ | 新規実装 | **そのまま流用** |

**新しく作るのは、街と外の見た目と、その土地の話だけである。**
戦闘まわりを触らないことが、規模を3倍にしても完成する唯一の条件になる。
