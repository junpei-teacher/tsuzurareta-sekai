# 『焚書の夜』アートバイブル

Phase 7 のアセット制作で**全員が従う規約**。
生成AIに投げるプロンプトも、フリー素材の選定も、手描きの修正も、すべてここに合わせる。

> **なぜ先に決めるのか**
> 設計書 8.1 の警告：素材の出所や色調が混ざると、画面全体が寄せ集めに見え、
> シナリオがどれだけ良くても安っぽくなる。**パレットと寸法は生成前に固定する。**

---

## 1. 寸法

| 用途 | サイズ | 備考 |
|---|---|---|
| 内部解像度 | **480 × 270** | 整数倍でスケール（×4 で 1920×1080） |
| マップタイル | **16 × 16** | 1部屋 28×14 マス＝1画面 |
| マップ上キャラ | **32 × 32** | 実際の体は 16×24 程度。上下に余白を持たせる |
| 敵（フィールド） | **32 × 32** | ボスは 48×48 |
| 敵（戦闘画面） | **64 × 64** | ボスは 96×96 |
| 立ち絵・顔グラ | **96 × 96** | 会話ウィンドウの左に置く |
| 背景（夜明けの書庫） | **480 × 270** | 1枚。エンディング全種で使い回す |

### どのキャラに何のアニメが要るか

**画面内を歩くのは主人公だけ。** NPCは部屋に立っているだけで、
ミラの移動は「会話のたびに別の部屋に現れる」という仕組みで表現している。
プレイヤーの目の前を歩くことは一度もない。

| 対象 | 必要なアニメ | 生成方式 |
|---|---|---|
| **主人公** | **4方向 × 歩行** | `template walking-4-frames`（1発/方向） |
| NPC（ミラ・司書長ほか） | **待機のみ**（南向き1方向） | `v3 custom`（1発） |
| 敵 | 戦闘画面の待機のみ | `v3 custom`（1発） |

主人公の歩行は反転で済ませない（燭台の光が左から当たるので陰影が破綻する）。

### 生成方式の使い分け（Phase 7 の検証結果）

| | template | v3 custom |
|---|---|---|
| コスト | 1発/方向 | 1発/方向（同額） |
| 歩行の前後運動 | **正しく出る** | **出せない** |
| 待機ポーズとの同一性 | 崩れる（顔が変わる・小道具が消える） | **完全に一致** |

v3 で歩行を3回試して3回とも別の壊れ方をした（脚が動かない／両足同時で跳ねる／
脚が左右に開く）。**v3 は正面視点の奥行きを解釈できない。** 骨格を持つ template との差で、
プロンプトで埋まる差ではない。

したがって——

- **歩かせるなら template。** そのかわり**手に何も持たせない**。
  小道具が消えるのが破綻の主因で、顔の微差は実寸ではほぼ判別できない
- **立っているだけなら v3。** identity が完全に保たれる

## 2. パレット（用途で2本に分ける・厳守）

**正は `tools/palette.ts`。** この表は説明用で、実装はそちらを参照する。

### なぜ1本ではダメだったか

当初は16色1本で組んでいた。最初のキャラを1体減色しただけで3か所壊れた。

| 症状 | 原因 |
|---|---|
| 顔と手が真っオレンジになった | **肌色が1色も無く**、最近傍が「炎」だった |
| 灰色のローブが緑になった | **中間グレーが無く**、「苔」に吸われた |
| 目に紫の点が出た | **藍と紫がスプライトに混ざった** |

**寒色（藍・紫・苔）はスプライトに混ぜてはいけない。** UI とエフェクト専用にする。

### ASSET 16色 — キャラ・敵・マップチップ

減色（`npm run palettize`）はこの16色だけを使う。

## 3. 光と陰影

- **光源は左上の燭台。** 陰影は右下に落ちる
- 明部は8番・7番、中間は6番・5番、影は3番・2番
- **アンチエイリアスを使わない。** 中間色でぼかさない
- グラデーションは禁止。段階は最大3段（明・中・暗）
- 輪郭線は1番（`#0a0806`）。ただし外周を全部囲まない（下側だけ、など）

## 4. PixelLab へのプロンプト骨格

**変えるのはキャラ固有の記述だけ。** 骨格は絶対に固定する。

```
16-color limited palette pixel art, candle-lit medieval royal library,
warm earth tones with dark stone background, light source from upper left,
hard pixel edges, no anti-aliasing, no gradients, no outline glow,
muted and grim, 1990s JRPG sprite style
--- character ---
[ここだけ差し替え]
```

### キャラ固有記述の書き方

| 要素 | 書く内容 |
|---|---|
| 立場 | apprentice / senior apprentice / old librarian / soldier / demon |
| 服 | dusty grey robe, ink-stained sleeves など。**素材と汚れを必ず書く** |
| 髪 | 色と長さ。1〜2色で表現できる範囲に |
| 持ち物 | 1つまで。多いとドット絵で潰れる |
| age / build | short, slight / tall, gaunt など |

**書かないこと**：表情の細かい指定（32pxでは表現できない）、
背景（透過で出す）、複雑な模様。

## 5. 検証チェックリスト（Phase 7 冒頭・1キャラで判定）

設計書 8.1 に基づく。**これが通らなければハイブリッドに落とす。**

- [ ] **4方向 × 3フレームの歩行で、同一人物に見えるか**（最大の関門）
- [ ] 32×32 のグリッドに正確に乗っているか。ぼやけていないか
- [ ] 上記16色に収まるか。収まらない場合、減色後に破綻しないか
- [ ] 立ち絵とマップキャラで、同一人物と認識できるか
- [ ] 生成物の利用規約（商用・再配布・クレジット表記）
- [ ] **1キャラあたりのクレジット消費量**（無料枠で何体作れるかの実測）

### 最初に作るキャラ：ミラ

理由：**立ち絵と歩行アニメの両方が必要**な唯一のキャラなので、
1体で両方のパイプラインを検証できる。しかも物語の核なので、
ここで品質が出なければ企画全体の見直しになる。

```
a slight teenage library apprentice, one year senior,
short messy dark-auburn hair tied back badly,
dusty grey work robe with ink-stained sleeves, worn leather apron,
holding a closed book against her chest,
tired but curious expression, no jewelry
```

## 7. 後処理（生成物をそのまま使わない）

1. **16色にインデックスカラー化**（GIMP または Aseprite）。上記パレットを固定で当てる
2. グリッドからずれていたらニアレストネイバーで整形
3. 目・口など顔の要点だけ手で打ち直す
4. 透過を確認（背景が残っていないか）

**PixelLab の出力が上記を満たすなら、1〜2は省略できる。**
それが Phase 7 冒頭で確かめたいことのひとつ。
