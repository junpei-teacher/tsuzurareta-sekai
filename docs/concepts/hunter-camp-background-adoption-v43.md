## 採用内容

v42候補を第二章 `hunter_camp` の静的背景として採用した。採用ファイルは `src/assets/series2/backgrounds/hunter_camp/middle.png`（960×540、正式森パレット138色使用、SHA-256 `f038c345fffc81ce54e3c6dd60ed8531ad9e08b02f68bcc150cd24ecc7f8459b`）。生成原本、実送信プロンプト、変換工程は `hunter-camp-background-trial-v42.md` に保持する。

背景は起動時に正式Manifestから読み、未読込・不正寸法なら従来のコード景観へ戻る。補修した幕、荷、木箱、橋の名残、踏み固めた土は静景に置き、洞角猪、手帳、消えない熾火、人物、会話、UIは動的層へ残す。熾火は戦闘前から残り、手帳は猪戦後に開いた状態で現れ、読後は閉じた冊子として残る。DEV「背景　4地域比較」のKキーも正式画像を使う。

## 検証

- `npm run build`：120モジュール、成功。
- `npm run verify:assets`：正式21エントリの寸法・透過・ハッシュ・欠落・余分なファイルを確認。
- `npm run verify:bundle`：25ファイル。生成原本と比較資料の混入なし。
- `npm run verify:hunter-camp-trial`：生成原本、138使用色、480×270からの整数2倍、正式画像との一致を確認。
- `npm run verify:hunter-camp-scene`：画像あり／なしの両方で、落ちた橋からの入場、洞角猪による通行停止、戦闘呼出、手帳の出現・調査・読後差分、HP・MP全回復、守護樹の窪地への開通を実Sceneで確認。戦闘勝利はコールバックで再現し、戦闘そのもののプレイ検証ではない。
- v42のブラウザDEV比較で三状態、人物と猪の接地、左右の歩行帯、手帳会話を目視確認。正式画像はv42派生とバイト単位で一致する。
