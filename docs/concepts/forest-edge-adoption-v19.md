## 書き出しと層の境界

DEV背景比較 → 2（森）→ Gで配置C → Mで静的素材を表示・保存する。
Mは配置Cの2原本が正常に読み込めた場合だけ有効。未読込・エラーをコード版で代替して素材を書き出さない。
Sは従来のコード版構図、Eは人物・UI付きの比較、Mは採用する静的景観と役割を分ける。
Eの表記も「本番未採用」から「開発比較（素材原本ではありません）」へ更新し、v19のファイル名で保存する。v18の保存済み比較資料は変更しない。

`renderForestEntranceLayers`でv18と同じ合成を行い、そのCanvasからPNGを書き出した。
Aの上64pxは画面外、下端7行の明色帯は表示対象外。y142から地面を置き、y187〜198の12行でなじませ、足跡の下に静かな土の面を重ねる。
原本の幹や葉は拡縮で変形しない。書出PNGの全画素が2×2単位で同色であること、上部の森林と下端の地面の色が原本に一致することを検査した。

採用PNGに含めるのは森林・地面・足跡の下地の土だけ。
人物・狼・靴跡・獣の足跡・光・薄霧・粒子・文字・UI・ガイドを含めない。
v18の人物入り合成PNGを本編素材として流用していない。

これは固定画面用の合成済み中景1点。遠景・中景・前景を独立して動かせる三層パララックス素材ではない。
他地域を同じ合成方法で量産する決定ではない。

## 実装

- 専用目録に画像URL・幅・高さ・不透明規格を登録。`new URL(..., import.meta.url)`でViteの正式出力へ載せる。SceneにdocsやpublicのURLを書かない。
- 起動時に既存の画像ローダーで読み、`SideViewScene`へImageMapを渡す。`forest_edge`以外へこの画像を流用しない。
- 未完了・欠落・naturalWidth/Height不一致なら元の`renderForestEntrance`を呼ぶ。画像がなくても探索・調査・戦闘へ進める。
- 採用画像の上へ、土用の茶色の足跡と既存の光・薄霧・粒子を描く。その後に本編の人物・敵・HUD・会話窓を描く。
- 足元y176、調査点x132、狼x302、会話窓y182、歩行・通行制限・戦闘能力・セーブ形式は変更しない。
- 実プレイで、狼が会話と逆の森側を向いている既存不一致を確認。探索中の苔背の狼は接地中心で左右反転し、左の村側へ向けた。森入口のDEV比較にも適用。戦闘描画は既定の右向きを維持する。

## 確認

### 自動検証（14項目）

build、verify:assets、verify:forest-art、verify:forest-scene、verify:bundle、verify:dist、verify:panels、verify:save、verify:intro-battle、verify:story-battles、lint:series2、balance:series2、verify:scope、verify:canonが通過。

- `verify:assets`：目録とファイルの一対一対応、命名・ID・寸法・透過、余分なファイルや欠落を検査。新カテゴリは採用時に規格を追加する。
- `verify:forest-art`：原本2枚のハッシュと構成値、正式PNGのハッシュ、全画素の整数2倍と原本色一致。
- `verify:forest-scene`：実SideViewSceneをテストダブルで動かす。画像あり／なしで左右歩行・会話・遭遇・未勝利の通行制限・勝利後の往復・狼の消失を確認。単体では未完了・幅0・幅違い・高さ違い・欠落の5ケースも検査。
- `verify:bundle`：既存のDEV/旧作混入検査に加えて、正式PNGが同一バイトで出力されJSから参照されることを検査。
- `git diff --check`：通過（既存の改行コード警告のみ）。

最終buildは6ファイル。正式PNGは `assets/middle-FgCHoP_p.png`（74.61kB）、JSは `index-Dny2juAy.js`（228.30kB / gzip 74.69kB）。
原本A/B・地面のDEVファイル・比較画面・素材書出UIは本番へ入らない。

`verify:forest-scene`の最初の実行はWindowsサンドボックスの`uv_os_get_passwd`で停止。許可された通常権限で実行後、テスト自身の「画面遷移後のキー解放1フレーム」を明示して再検査し通過した。ゲームの遷移処理は変更していない。

### ブラウザの実プレイ

既存の保存を避けるため専用origin `http://127.0.0.1:5189/`を使用。画面上で新規状態を確認し、DEVの第二章入口から開始した。
ブラウザの内部保存を直接書き換えず、通常のキー操作で村門の出発会話→森の境界→森入口と進んだ。

- 通常の左右歩行と足跡の調査会話。960×540とCSS480×270で接地・足跡・狼・本文を確認。
- 更新後の「つづける」から森入口を再開できることを確認。
- 村側を向く狼との会話→通常戦へ接続。SLANEを2回詠唱して勝利し、経験値+10の報酬、探索への復帰を確認。Lv1、HP25/30、MP72/90、経験値10。
- 勝利後は狼が消え、目的が涸れ沢の狩人捜索へ更新される。背景は同じ採用素材のまま。
- 開通した右端から涸れ沢へ進み、従来の沢の背景で表示されることを確認した。検査時のブラウザwarn/errorは0件。
