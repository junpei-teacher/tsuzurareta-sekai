# 世界のルールを書き換える

ゲームを動かしている `index.html` をエディタで開いて、`GAME_RULES` を探します。

```html
<script>
  window.GAME_RULES = {
    damageMultiplier: 1,
    infiniteMp: false,
  };
</script>
```

## まずは、ダメージを100倍にする

1. 普通の設定で敵に `ROZHA` を唱え、ダメージを覚えます。第1章の「反故紙の人形」なら、倒さずに何度も試せます。
2. `damageMultiplier: 1` の数字だけを `100` に変えます。
3. ファイルを保存して、ブラウザを再読み込みします。
4. 同じ相手に `ROZHA` を唱えて、表示されるダメージを比べます。

倍率は1〜1000000で試せます。敵の防御や相性を計算した後の、攻撃呪文のダメージに掛かります。回復量・やけどの継続ダメージは変わりません。もともと無効な属性は無効のままです。

## 次は、MPを無限にする

`infiniteMp: false` を `infiniteMp: true` に変えて、保存・再読み込みします。MPが0でも呪文を唱えられ、不発でもMPが減りません。

人形は通常でもMPを消費しないので、この違いは普通の敵との戦闘で確かめます。

## 元に戻す

数字を `1`、MP無限を `false` に戻して、保存・再読み込みします。ルールの設定はセーブには保存されません。実験中に発見した呪文などのプレイ記録は、通常どおり残ります。

再読み込みするとタイトルから始まります。「つづきから」を選ぶと、自動保存された場所から再開できます。会話や戦闘の途中で閉じた場合は、その直前の区切りから再開します。

## ChromeのConsoleで試す

開発者ツールのElementsにあるコメントにも、次の命令を載せています。Consoleに入力してEnterを押すと、その場で反映されます。保存・再読み込みは不要です。

```js
// ダメージ100倍
window.GAME_RULES.damageMultiplier = 100
// MP無限
window.GAME_RULES.infiniteMp = true
// ダメージを元に戻す
window.GAME_RULES.damageMultiplier = 1
// MP消費を元に戻す
window.GAME_RULES.infiniteMp = false
// 両方まとめて元に戻す
window.GAME_RULES = { damageMultiplier: 1, infiniteMp: false }
```

Consoleでの変更は再読み込みで元に戻ります。Elementsでscriptの文字を編集するだけでは、実行中の設定は変わりません。

## タブを閉じても、つづきから

現在の章・部屋・位置・向き・HP/MP・道具・倒した敵・会話とミラの巡回の進行を自動保存します。呪文帳や見た結末は、これまでどおり保存します。

会話や戦闘の途中では、その直前の区切りから再開します。禁書の入力中は、禁書の入力開始から再開します。エンディング到達後は途中経過を消し、集めた記録を残します。「はじめから」を選んで署名を終えると、新しい周回の途中経過に置き換わります。

保存先は、このブラウザのこのサイト用のlocalStorageです。同じChromeのプロフィール・同じサイトのアドレス（開発時は同じポート番号）で開いてください。サイトデータを削除するとセーブも消えます。閲覧履歴だけの削除ではセーブは消えません。シークレットモードでは、ウィンドウをすべて閉じた後までの保存はできません。

この機能を追加する前のセーブには現在地が入っていないので、過去に閉じた時点への復元はできません。更新後に遊んだ区切りから、自動保存が始まります。

## どのファイルを開く？

- 開発サーバー（`npm run dev`）で遊ぶときは、プロジェクト直下の `index.html` を編集します。
- ビルド済みのゲームを配布するときは、`npm run build` で作られた `dist` フォルダー一式を渡します。受け取った人は、その中の `index.html` を編集します。ルールの変更だけなら再ビルドは不要です。`dist` を配信するローカルサーバーで開き、編集後は再読み込みしてください。
- `npm run build` を再実行すると `dist` の編集は上書きされます。配布元の初期設定は、プロジェクト直下の `index.html` で変更します。

最初は数字と `false` / `true` の部分だけを書き換えましょう。カンマや括弧もプログラムの一部です。
