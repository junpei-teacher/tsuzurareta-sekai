# 世界のルールを書き換える

ゲームを動かしている `index.html` をエディタで開いて、`GAME_RULES` を探します。

```html
<script>
  window.GAME_RULES = {
    damageMultiplier: 1,
    infiniteMp: false,
  };
</script>
```

## まずは、ダメージを100倍にする

1. 普通の設定で敵に `ROZHA` を唱え、ダメージを覚えます。第1章の「反故紙の人形」なら、倒さずに何度も試せます。
2. `damageMultiplier: 1` の数字だけを `100` に変えます。
3. ファイルを保存して、ブラウザを再読み込みします。
4. 同じ相手に `ROZHA` を唱えて、表示されるダメージを比べます。

倍率は1〜1000000で試せます。敵の防御や相性を計算した後の、攻撃呪文のダメージに掛かります。回復量・やけどの継続ダメージは変わりません。もともと無効な属性は無効のままです。

## 次は、MPを無限にする

`infiniteMp: false` を `infiniteMp: true` に変えて、保存・再読み込みします。MPが0でも呪文を唱えられ、不発でもMPが減りません。

人形は通常でもMPを消費しないので、この違いは普通の敵との戦闘で確かめます。

## 元に戻す

数字を `1`、MP無限を `false` に戻して、保存・再読み込みします。ルールの設定はセーブには保存されません。実験中に発見した呪文などのプレイ記録は、通常どおり残ります。

再読み込みするとタイトルから始まります。戦闘の途中経過は引き継ぎません。

## どのファイルを開く？

- 開発サーバー（`npm run dev`）で遊ぶときは、プロジェクト直下の `index.html` を編集します。
- ビルド済みのゲームを配布するときは、`npm run build` で作られた `dist` フォルダー一式を渡します。受け取った人は、その中の `index.html` を編集します。ルールの変更だけなら再ビルドは不要です。`dist` を配信するローカルサーバーで開き、編集後は再読み込みしてください。
- `npm run build` を再実行すると `dist` の編集は上書きされます。配布元の初期設定は、プロジェクト直下の `index.html` で変更します。

最初は数字と `false` / `true` の部分だけを書き換えましょう。カンマや括弧もプログラムの一部です。
