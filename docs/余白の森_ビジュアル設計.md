# 『余白の森』ビジュアル設計

> 画面方式、座標、人物寸法、アセット工程は[『余白の森』設計書](./余白の森_設計書.md)と[制作手順書](./余白の森_制作手順書.md)を優先する。

## 1. 目標

戦闘と詠唱の操作感は第一作から変えない。十年後であることは、技術の発達ではなく、
屋外の光、色の広がり、情報整理、画面遷移の滑らかさで見せる。

> **第一作が「火に照らされた紙」なら、第二作は「木漏れ日に透ける記憶」。**

## 2. 変えないもの

- 内部座標 480×270、実描画 960×540
- 整数倍スケールとドットの輪郭
- タイピングによる詠唱
- 呪文帳、欠けた綴り、MP＝インク
- ターン制戦闘、レベル1〜5、武器は杖のみ（防具・アクセサリーなし）
- 1固定画面＝1舞台、カメラ無し
- A-Zの語を強調色で拾う文字組み

## 3. 色の方向

第一作の煤、焦茶、炎の橙から離れ、自然光の色相差を使う。

| 用途 | 基調 | 役割 |
|---|---|---|
| 画面外・夜 | 深い青緑 | 第一作の黒より空気を含ませる |
| UI面 | 暗い松葉色 | 世界から浮かない半透明感 |
| 本文 | 温かい象牙色 | 長文の可読性 |
| 補助文字 | 灰緑 | 情報の階層化 |
| 主強調 | 若い金 | 名前、選択、木漏れ日 |
| 副強調 | 水色を含む青緑 | 指輪、記憶、魔力 |
| 危険 | 珊瑚色 | 血より警告として見せる |
| 忘却 | 薄い菫色から無彩色 | 色が抜ける演出に使う |

一つの画面に全色を出さない。場所ごとに主役を決める。

- 村：苔、土、藁、朝の金
- 浅い森：若葉、青空、湿った樹皮
- 深い森：青緑、藍、蛍光する胞子
- 遺跡：黒曜、古い金、菫
- 忘却：周囲の彩度を落とし、名前だけを象牙色で残す

## 4. 現代的に見せる要素

### 情報の階層

- シリーズ名は小さく、作品名を大きくする。
- 選択中の項目は矢印だけでなく、面、縁、わずかな光で三重に示す。
- HP、MP、状態異常は位置と色を固定し、戦闘とフィールドで読み方を揃える。
- 操作ヒントは右下へ固定し、本文と競合させない。

### 奥行き

- UI窓へ1～2pxの影、内側の上辺へ1pxの反射を置く。
- キャラクターと敵の足元へ接地影を置く。
- 前景の葉、中央の人物、背景の光を三層に分ける。
- ブルームは文字の上へ掛けず、環境光だけに使う。

### 動き

- タイトルには遅い木漏れ日と浮遊粒子。
- 章の扉は紙の焼けではなく、葉影が開いて文字が現れる。
- 会話窓は上下移動させず、2～3フレームの明度変化で開く。
- 戦闘開始は黒フェードではなく、周辺の彩度が落ちて敵へ焦点が集まる。
- 被弾時は短い停止、1pxの揺れ、輪郭光を組み合わせる。

## 5. タイトル画面

- 背景は深い森の縦グラデーション。
- 画面中央に欠けた円環を薄く置き、指輪と「余白」を同時に示す。
- 上段に小さく「綴られた世界」。中央に「余白の森」。
- 木漏れ日の金と、記憶を示す青緑の二光源。
- 12～18個の微粒子を低速で漂わせる。ランダムではなく決定的な配置にする。
- メニューは中央下。選択中だけ背景面が一段明るくなる。

## 6. 会話画面

- 立ち絵64pxと3行表示は維持。
- 話者名ラベルを窓に重ね、選択色は人物固有色とする。
- 地の文と台詞の明度差を維持する。
- 幼なじみの名前が欠ける場面では、文字を置換せず、字幅だけ残して消す。
- 記憶の穴はノイズではなく、音が一瞬減り、色が抜けることで表現する。

## 7. 戦闘画面

共通の呪文物理とターン制は変えず、次を表示層として追加する。

- 場所ごとの背景色と薄い環境シルエット
- 敵の接地影と、呼吸する1～2pxの上下動
- 入力欄のフォーカス面と現在MPの即時比較
- 詠唱確定時の属性色フラッシュ
- ダメージ数字の短い上昇と減速
- ボス固有の画面縁演出
- 指輪の反応は短い金属音と欠けた円の一度の脈動で見せ、通常の入力語を弾く万能防御にはしない

通常の戦闘テンポ、ターン順、ダメージ式、呪文ハッシュは変更しない。

## 8. 実装順

現在の工程と完了状態は制作手順書を正とし、生成範囲はアートバイブル第10章に従う。

1. 現行コード版で、村への報告から森入口までの構図、場所色、奥行き、人物と会話窓の余白を整える。
2. 代表画面が合格したら、全画面の細部完成を待たずPixelLabで背景・敵・人物の少数試作へ進む。
3. 生成候補と現行の簡略ドットを同寸・同じUIで比較し、採用する制作方式とコードで残す層を決める。
4. 最初の代表比較をユーザーへ見せて方向を確認し、共同倉、他人物、他地域へ展開する。
5. 採用素材に合わせて光、粒子、動き、音を仕上げ、全編を通常導線で通す。

背景の材質と色彩を豊かにしつつ、人物の輪郭・頭身・識別記号は今の簡略ドットを基準にする。
UI、文字、光、霧、粒子、画面遷移、物語小物の正確な形と状態はコードで維持する。
全てを生成画像へ置き換えることを完了条件にはしない。
