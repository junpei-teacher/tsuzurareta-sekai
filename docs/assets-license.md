すべて **PixelLab** で生成し、このリポジトリで加工したもの。
生成物の権利は PixelLab の利用規約（https://pixellab.ai/termsofservice）に従う。

| | 生成方式 |
|---|---|
| 主人公 | `create_character` v3 ＋ `animate_character` pro（歩行） |
| ミラ・司書長・兵士・抹消された名前の者 | `create_character` v3 |
| 立ち絵 | `create_portrait_character`（フィールドの姿から変換） |

| タイル・家具 | `create_topdown_tileset` / `create_map_object` |
| 階段 | **生成物ではない。** `src/scenes/field.ts` の `renderStairs()` で手描き |

## 音

### 曲（3本・**Suno で作成**）

| ファイル | 場面 | 尺 |
|---|---|---|
| `scene1_BGM.mp3` | オープニング／第1章／エンディング | 3:45 |
| `scene2and3_BGM.mp3` | 第2章／第3章 | — |
| `LastBattle.mp3` | ラスボス戦 | — |

置き場所は `public/assets/bgm/`。対応表は `src/core/audio.ts` の `TRACKS`。

**7つの場面を3本でまかなう。** 鳴らし分けるのは3回だけである。

- **第1章の曲がエンディングで戻ってくる。** 同じ夜が終わったことを、説明せずに伝える
- 第2章と第3章は同じ曲。**階段を降りても音は途切れない**
  （切り替え判定はIDではなくファイル名で行う。`audio.ts` の `play`）
- **雑魚戦では曲を変えない。** 曲が変わるのはラスボスだけ。
  変える回数を絞ることで、変わったこと自体が合図になる

> **利用条件は公開前に必ず確認すること。**
> Suno は加入しているプランによって生成物の商用利用可否と表記義務が変わる。
> 教材配布・Web公開のどちらであっても、当時のプランの規約を確認してから公開する。
> 確認した内容をここに書き足すこと。

### 効果音（**自作・音声ファイルなし**）

`src/core/sfx.ts` が WebAudio の発振器と雑音から**その場で合成する。**
素材ファイルは1つも無いので、出典も利用条件も発生しない。

音色の方針は「古い書庫の音。電子音にしない」。
打鍵は木と紙、呪文は空気の破裂、被弾は鈍い打撃で作ってある。
部品は「減衰する単音」と「帯を絞った雑音」の2つだけで、
**増やさないことが音色の揃っている理由**になっている。

鳴る場所：打鍵・消す・決定・取消・カーソル・足音・命中・被弾・撃破・逃走・
扉・階段・呪文の習得・頁送り・拒否、および詠唱の5帯（DUD〜MYTH）と「届かない言葉」。

詠唱の音は **CastFx の炸裂の瞬間に合わせてある**（`castFx.ts` の `burstIn`）。
神話級は1.3秒ためてから炸裂するので、命中音もそこまで遅らせている。
**どちらか一方だけ直すとズレる。**

**回復呪文（`element: "HEAL"`・7本）だけは雑音を使わない。**
他の音がほとんど雑音（＝物がぶつかる音）でできているので、
雑音の無い和音が鳴った瞬間に、何が起きたかが分かる。
攻撃呪文がどれも下へ落ちるのに対し、回復だけが上へ昇って残る。
帯が上がるほど根音を下げて長く伸ばす（G4→E4→D4→C4）。
**回復7本のうち3本がアンコモンなので、ここを分けないとほとんど同じ音になる。**

**神話級の攻撃は他と作りを変えてある**（`sfx.ts` の `myth`）。
凄みは音量では出ない。溜めの低音を2本わずかにずらした「うなり」、
炸裂直前に音を吸い上げて断ち切る「間」、整数比から外した高音の「鐘」、
そして少し遅れて沈む二段目——この4つで出る。**どれも大きくしない。**

なお神話級の回復「完本」は、凄みではなく回復の音で鳴る。全回復だからである。

音量調整はブラウザで実測する（`__dbg.sfx` から単体で鳴らせる）。
帯を絞った音は数字どおりの大きさにならないので、耳と実測の両方で決めること。

## 操作

音量は `-` と `=`。**呪文は A-Z と 0-9 だけ**なので、詠唱中に押しても綴りに入らない。
0 まで下げれば消音。設定は localStorage に残る。
