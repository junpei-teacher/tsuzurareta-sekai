# Workers 公開手順の修正版

- `index.html`：公開中のページを元に修正した HTML。既存の URL 入力、Git コマンドのコピー、進捗保存を維持し、Kiro 用プロンプトと Workers の公開・確認手順を追加。
- `デプロイ用プロンプト.txt`：配布用。デスクトップの同名ファイルも更新済み。
- `デプロイ用プロンプト_修正前.txt`：元の配布ファイルの控え。公開する必要はない。

このフォルダーは手順サイト用の修正成果物であり、ゲームの公開用 `public` には入れていない。
公開サイトのソース配置・Git 接続先が未確認なので、公開 URL への反映は未実施。
ソースが判明したら、手順サイトの配信対象の `index.html` を修正版に置き換え、同じ配信ディレクトリに配布用テキストを置く。サイトがフレームワークで生成されている場合は、そのソース側に同じ変更を反映する。

## 確認済み

- HTML の ID 重複がないこと
- ページ内のコピー用プロンプトと配布用テキストが Worker 名の差し込み以外で一致すること
- ページ内 JavaScript の構文チェック

ブラウザーでの見た目・コピー操作、本番デプロイは未確認。

## 修正の理由

元ページの Cloudflare コマンド自体は Workers 向けだった。一方、配布プロンプトには `assets.directory` の指定、Pages 用設定の置き換え、既存構成の分類、ビルドと dry-run の検証が明記されていなかった。これは Pages 用構成が残る余地を生むが、過去に Kiro がその設定を生成した直接の理由まではチャット履歴なしでは断定できない。
元の配布ファイルの `git-push-guide.git` は Worker 名に使う値として不適切なので、`.git` を付けないよう明記した。
